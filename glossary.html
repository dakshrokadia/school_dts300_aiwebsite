Glossary

Every technical word used on this site, in plain English. These are the words worth knowing before reading anything else about AI.

AI winter
A period where interest and funding in AI dried up because the results did not match what had been promised. There have been two, one in the 1970s and one in the late 1980s. See the history page.
Algorithm
A set of steps for doing something. That is all it means. A recipe is an algorithm. The word sounds far more mysterious in the news than it is.
Bias
When a system treats some group of people unfairly because the examples it learned from were unfair. It is not the system choosing to be unfair. It is copying a pattern it was shown. See the ethics page.
Chatbot
A program you type to and get replies from. Early ones like ELIZA followed fixed rules. Modern ones are built on large language models.
Expert system
An older kind of AI that followed a long list of rules written down by specialists. Popular in the 1980s. It worked, but only inside the exact area it was built for.
Large language model (LLM)
A system trained on an enormous amount of text so that it can predict which words should come next. This is what ChatGPT and similar tools are built on. Predicting the next word is genuinely all it is doing, which is why it can sound confident and still be wrong.
Machine learning
The general name for software that learns from examples instead of following rules a person wrote. Almost everything called AI today is machine learning.
Model
The finished result of training. It is the thing that has learned the patterns and can now be used on new information. When people say "the model got it wrong", this is what they mean.
Neural network
One method for doing machine learning, loosely based on how brain cells connect to each other. The comparison to a brain is much looser than it sounds, and you do not need to understand brains to understand what it does.
Training
The process of showing a system examples until it gets good at a task. See what is AI.
Training data
The examples used during training. This matters more than almost anything else, because a system can only learn what its examples contained. Show it only ginger cats and it will struggle with a black one.
Transformer
A design introduced in 2017 that handles language far better than what came before. It is what the T in ChatGPT stands for, and every well known chatbot is built on it.
Turing test
Alan Turing's 1950 suggestion that if a person cannot tell whether they are talking to a human or a machine, the question of whether the machine is really thinking stops being useful. More of a thought experiment than a test anyone actually runs.
